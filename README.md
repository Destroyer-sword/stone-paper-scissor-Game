# 🪨📄✂️ Stone Paper Scissor Game

[![Netlify Status](https://api.netlify.com/api/v1/badges/site-status/deploy-status)](https://stonepaperscissorsgamee.netlify.app/)

A fun, interactive, and browser-based implementation of the classic **Stone Paper Scissors** (Rock Paper Scissors) game. Play against the computer, keep track of your live score, and enjoy smooth animations.

Experience the game live in your browser:

## ✨ Features

- **Player vs. Computer:** Battle against random computer choices in real-time.
- **Dynamic Score Tracker:** Automatically updates the score after every round for both player and computer.
- **Visual Feedback:** Displays interactive hand/game images for both choices.
- **Instant Outcome Display:** Clear visual indicators for wins, losses, or ties.
- **Responsive Layout:** Works smoothly on mobile devices, tablets, and desktop browsers.

---

## 🛠️ Built With

- **HTML5:** Semantic structure and game UI layout.
- **CSS3:** Custom styling, layout design, and responsive elements.
- **JavaScript (ES6):** Game logic, score calculation, dynamic updates, and DOM manipulation.
- **Netlify:** Continuous deployment and hosting platform.

---

## 🎮 How to Play

1. Select your move (**Stone**, **Paper**, or **Scissor**) by clicking one of the choices.
2. The computer will randomly generate its choice at the same time.
3. The game calculates the round winner based on standard rules:
   - 🪨 **Stone** beats ✂️ **Scissor**
   - 📄 **Paper** beats 🪨 **Stone**
   - ✂️ **Scissor** beats 📄 **Paper**
4. Watch the score update in real-time and try to beat the high score!
